Fashion Trend at Scale

About the Project

Fashion Trend at Scale is a data analytics project that analyzes fashion product data to understand customer ratings, sales, and popular product categories.

Objectives

- To analyze fashion sales data.
- To identify popular fashion categories.
- To understand customer ratings.
- To visualize sales trends using graphs.

Dataset

The dataset contains fashion product information, including product categories, sales quantity, sales amount, and ratings.

Tools Used

- Python
- Jupyter Notebook
- Pandas
- Matplotlib

Analysis

The project uses charts and graphs to analyze sales performance, product categories, and customer ratings.

Conclusion

This project helps understand fashion trends and sales performance through data analysis.
